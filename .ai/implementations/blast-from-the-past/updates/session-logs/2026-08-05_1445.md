## Implementation

- Added display-only Warp neighborhood smoothing, covariance, eigensolve,
  bounded anisotropic scales, deterministic sparse fallback, and snapshot/
  preparation telemetry. Tests prove solver positions are unchanged and axes
  are finite, orthonormal, right-handed, positive, and bounded.
- Added a versioned packed surface frame: four float32 vectors per fluid
  particle, plus tank bounds and rigid pose. Default 1,000-particle wire size
  is 85,336 bytes. Round-trip, malformed data, replay identity, finite input,
  and size gates pass.
- Added a self-contained raw-WebGPU ES module: analytic ellipsoid depth,
  additive thickness, two-pass bilateral smoothing, reconstructed normals,
  Fresnel/refraction/Beer--Lambert water, procedural floor/grid, and an
  oriented orange rigid box. The module validates WGSL compilation and creates
  every render pipeline asynchronously.
- Added Gameplay Surface/Particles controls, optical/debug parameters,
  browser-local orbit/pan/zoom/reset, device failure fallback, and separate
  pack/upload/render telemetry. Adaptive/Uniform remain VTK-only.
- Surface live/replay routing bypasses VTK scene update and JPEG generation;
  switching to Particles immediately renders the retained snapshot and
  switching back republishes the same replay frame.

## Browser findings

The first restart exited, producing the reported apparent application crash;
the service was relaunched and kept under an active terminal session. The
first browser run then remained at `WAITING`. Root cause was Trame-client 3.12
slot-variable shadowing: `Handler(variable="surface_frame")` created a local
ref with that name instead of reacting to server state. A distinct slot name
plus nested `ClientStateChange(... handler.run($event))` fixed it. Local
external-script copying also had to be redirected from immutable
site-packages to `/tmp/pysph-trame-client-scripts`.

Windows Edge 151 then completed the real WSL websocket/CUDA/WebGPU path on the
NVIDIA Blackwell adapter. At a 1280x720 browser viewport, two replays measured:

- WebGPU completion `3.300/5.800 ms` median/p95;
- upload `0.000/0.100 ms` median/p95;
- server pack `0.182/0.224 ms` median/p95;
- 85,336 bytes/frame and zero dropped/stale frames.

Final, depth, thickness, and normals were captured and inspected. The impact
surface is continuous, the rigid box is visible/occluding, and camera, resize,
replay, and Surface/Particles switching passed.

The VS Code editor browser later rejected a WGSL compound assignment to an
`xy` swizzle and correctly fell back to particles. Replacing it with a
whole-`vec4` assignment fixed the portability issue; a regression contract
now rejects multi-component swizzle compound assignments. A fresh default-
backend Edge run completed 250 steps and reported the surface renderer
`READY` without an error.
