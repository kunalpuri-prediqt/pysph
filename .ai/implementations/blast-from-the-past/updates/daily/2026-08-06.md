# Daily update - 2026-08-06

## Warp gameplay/WebGPU acceptance closeout

Hands-on review of the pending gameplay and surface prototypes found three
material defects: Cancel could not preempt a CUDA step, rigid contact used a
bounding sphere that made the box hover, and the 1,000-particle surface
visibly retained individual lobes.

Cancellation now escalates to terminate/kill after a short cooperative grace
period. Rigid contact uses oriented-box plane support and the upright box
starts on the floor. Gameplay exposes bounded Rich 7k and Fast 1k presets,
rejects spacing below `0.04 m`, and restores scientific spacing when leaving
Gameplay. The screen-space reconstruction/material was retuned; Rich is more
continuous and remains comfortably GPU-real-time locally.

The actual Rich run completed 250 steps at solver median `2.345 ms`, server
pack median `0.580 ms`, and WebGPU completion near `4.0 ms`. Its `599,040 B`
base64 frame exceeds the Fast 96-KiB transport gate, so binary transport or
display decimation remains required for remote Rich use. An actual browser
Cancel stopped a long run at step 85 and returned to `cancelled` in about
1.2 seconds.

Validation: full Warp separation `79 passed` with two installed-Warp warnings;
studio/transport `34 passed`; Node WebGPU contracts `6 passed`. Reviews remain
ready for prototype-owner inspection; no commit was made.

## NASADEM shallow-water geospatial profile

ADR-0014 and the approved Tier-2 plan add a fourth, isolated Geospatial
profile. Warp evolves a 256² conservative shallow-water grid with hydrostatic
Rusanov fluxes, wet/dry positivity, CFL stepping, Manning friction and explicit
boundaries. Static terrain and dynamic depth/speed use separate versioned
uint16 transports; a raw-WebGPU heightfield renderer provides terrain normals,
material/contours, lighting/fog, continuous water, shoreline/speed foam,
camera/reset and separated renderer telemetry.

The exact spawned worker measured `0.346/1.425 ms` median/p95 over 300 steps on
the RTX 5090 with relative volume drift `6.04e-8`. The final editor-browser run
completed 600 steps, reported WebGPU READY at `7.70/19.80 ms` median/p95, and
retained `1.19e-7` volume drift. A browser race where dynamic water could beat
the one-time terrain upload is fixed with bounded latest-frame deferral and
run/mount republishing.

Official NASADEM N43E006 metadata and URL were resolved, but Earthdata returned
HTTP 401 without owner authentication. The strict importer is complete and
records checksums, WGS84 bounds, EGM96 datum and processing while keeping NASA
elevation, synthetic barrier and synthetic initial water separate. The studio
automatically uses the prepared asset when present; until then it visibly says
`synthetic-valley-fixture`. No third-party DEM was substituted.

Validation: full Warp separation `86 passed`; studio/transport/importer `47
passed`; Node WebGPU `11 passed`; compile/syntax passed. Review is ready with
the external-data gate open; no commit was made.

## Procedural Terrain SPH profile

ADR-0015 and the approved Tier-2 plan add a fifth, isolated `Terrain SPH`
profile. It is genuine uniform 3D Warp WCSPH, not the regional SWE or gameplay
PBF solver. A configurable Gaussian hill is sampled as a filled,
floor-exclusive fixed-solid boundary, while the VTK scene renders the same
center/height/radii as a smooth normal-generated earthy surface.

The matched 250-step flat/hill comparison at `dx=0.1` completed finite with
zero relative fluid-mass drift and bitwise-stationary hill coordinates. The
hill changed 503/1,000 final fluid positions by more than `1 mm`, with
`9.76 mm` RMS and `13.58 cm` maximum difference, and slowed the surge front by
`3.11 cm`. Warm solver median was `8.13 ms` with the 72-particle hill versus
`5.34 ms` flat. The exact worker passed pause/step/resume/save, and generic
preemptive cancellation remains covered.

The editor-browser run completed 250/250 and visibly showed the pressure-
colored water front against the smooth hill. The first `/tmp`-cache run took
`62.97 s` because a generated Warp module compiled for about one minute; the
cached solver timing above is reported separately. Validation: Warp separation
`88 passed`, studio/transport/importer `51 passed`, Node tests `2 suites`,
focused Terrain SPH studio tests `5 passed`, and the CUDA hill test passed.
Review is ready; no commit was made.

Post-review hands-on switching found a Terrain-to-Gameplay state leak: the
completed Terrain result left `obstacle_mode=hill` in shared UI state and the
Gameplay validator rejected it. Profile routing now forces Gameplay's floating
body and restores the prior scientific obstacle after leaving Terrain. The
exact editor reproduction completed Gameplay 250/250 with 7,020 fluid and 170
body particles in 1.98 seconds; the failure banner is gone.
